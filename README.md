# E-Commerce Web Application – Manual Testing

## Project Overview

This project involves manual testing of the SauceDemo e-commerce web application. The project covers the complete testing process from test planning and test case design to test execution, defect reporting, retesting, regression testing, and SQL validation.

## Application

SauceDemo – E-Commerce Web Application

## Role

Manual Tester

## Testing Scope

The following modules are covered:

- Login
- Product
- Cart
- Checkout

## Testing Activities

- Requirement Analysis
- Test Planning
- Test Scenario Design
- Test Case Design
- Test Data Preparation
- Functional Testing
- Smoke Testing
- Sanity Testing
- Test Execution
- Defect Reporting
- Retesting
- Regression Testing
- SQL Validation
- Test Summary

## Tools & Technologies

- Manual Testing
- Microsoft Excel
- SQL
- Jira

## Project Objective

To verify that the major e-commerce workflows function as expected and to identify, document, and validate defects through a structured manual testing process.
